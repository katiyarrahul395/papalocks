KEITHLOCKS AI - PUBLIC NETLIFY VERSION

1. Upload this whole folder to Netlify (or drag the folder's contents into a Netlify deploy).
2. In Netlify: Project configuration -> Environment variables -> Add variable.
   Name: OPENAI_API_KEY
   Value: your OpenAI API key
3. Redeploy the site.
4. Share the resulting https://YOUR-SITE.netlify.app URL.

IMPORTANT: Never put the OpenAI key inside index.html. The key belongs only in Netlify's environment variables.
This is an unofficial fan-made AI project and is not affiliated with Keithlocks.
